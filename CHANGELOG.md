## 0.1.0

- Two MCP tools, `botus_read` and `botus_apply`, with optional native registration.
- Sparse sheets, typed cells, bounded formulas and atomic edits with revision checks and durable retry receipts.
- Host-owned persistence, private ownership, explicit sharing, permitted fork access and current-policy revocation.
- Complete bundled agent skill and embedded functional reference for reads, writes, formulas, access and limits.
- Published Core 0.9.3 and Meta 0.9.3 host integration, with no Git dependency or separate Botus database.
- MIT OR Apache-2.0 licensing. WK1 compatibility and macros remain unsupported.
